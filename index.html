What you see in game

Most of the suite is built for arena and dungeons, where you need to know what just happened without reading a combat log. These are taken from real matches.

These are only a few of them. There are many more features in the suite, from bags, damage meters and Mythic+ tools to chat, minimap and dozens of quality-of-life fixes. Install it and type /midnight to see everything.

Move anything with Unlock Mode

Type /unlock and every element in the suite becomes a box you can drag. Snap boxes to each other or to the edge of the screen, or type exact offsets when dragging isn't precise enough.

Profiles and presets

Save your setup as a profile, share it as an import string, or start from a preset. Full Export packs the whole suite into one string.

Spec overrides

Give a setting a different value per spec, and choose where things show: in combat, dungeons, raids, arena, battlegrounds or delves.

Search every setting

Type in the sidebar to find a setting on any page. The footer shows how much CPU the whole suite is using right now.

The Updater

A small Windows app that installs MidnightEssentials and keeps it current. It checks GitHub for the newest version, shows you what changed, and swaps the addon folders in about a minute.

Only touches its own folders

It replaces the MidnightEssentials folders in Interface\AddOns and nothing else. Your other addons stay as they are, and a module that was removed in a new version gets cleaned up.

Your settings stay put

Settings live in the WTF folder, which the Updater never opens. If a step fails, your previous version is put back.

If Windows warns you

The app isn't code-signed yet. On "Windows protected your PC", click More info, then Run anyway. If Smart App Control blocks it, install by hand instead.

Installing by hand

No Updater, or not on Windows? It takes a minute.

  1. Download MidnightEssentials.zipFrom the button at the top of this page, or the GitHub releases.
  2. Close World of WarcraftOr type /reload once you're done.
  3. Extract every folder into AddOnsReplace the old ones when Windows asks. World of Warcraft\_retail_\Interface\AddOns
  4. Start the gameYour settings are still there.

Slash commands

/midnightOpen the settings window. /mne works too.
/unlockOpen Unlock Mode to move and anchor things.
/eeJump straight to Global Settings.
/qolOpen the Quality of Life page.
/ovReopen the summary of your last Mythic+ key.
/rlReload the UI.

Questions

Which versions of the game does it support?

Retail and WoW Forever. The same download works on both. Modules a client can't support switch themselves off there, so you never need a second copy.

Will updating reset my settings?

No. Settings live in the WTF folder, and both the Updater and a manual install only replace folders in Interface\AddOns.

How do I turn a module off?

Every module has a power button next to its name in the settings sidebar. Some switch off right away, others after a /reload.

Can I share my setup with a friend?

Yes. Open Profiles & Presets, export your profile as a string and send it. They paste it into Import. Full Export covers the whole suite at once.

Does it work next to my other addons?

Yes. Switch off any module you'd rather use another addon for. Bags steps aside if you already use a bag addon like Baganator or Bagnon until you pick one, and Nameplate Auras sits on top of whatever nameplates you use.

Where do I report a bug?

In #bug-reports on the Discord. Say what you were doing, and paste the error text if one appeared.

Is it free?

Yes, all of it. If you'd like to support it there's a Patreon, but nothing is locked behind it.
