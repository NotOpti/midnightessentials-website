    How it works

    Four steps, about a minute.

    The first time, unzip the Updater anywhere you like and run it. It remembers your World of Warcraft folder for next time.

    1. Download and unzipGet MidnightEssentialsUpdater.zip and run the .exe inside it.
    2. Choose your game folderIt fills in your World of Warcraft folder from Windows when it can. The root folder, _retail_ or AddOns all work.
    3. Press UpdateIt shows your installed version, the latest release and how many addon folders it found, then downloads and installs.
    4. Reload the gameStart the game, or type /reload if it is already running.

    What it changes

    Only MidnightEssentials folders

    • SwapThe MidnightEssentials folder and every ME_ folder in Interface\AddOns.
    • CheckThe download is checked before anything is replaced.
    • UndoIf a step fails, your previous version is put back as it was.

    What it leaves alone

    Your settings and other addons

    • KeptYour settings. They live in the WTF folder, not in AddOns.
    • KeptEvery other addon in your AddOns folder.
    • KeptYour game files. Nothing outside Interface\AddOns is touched.

    If Windows warns you

    Windows may ask first.

    The Updater isn't code-signed yet, so Windows can't tell who made it and may stop it the first time.

    "Windows protected your PC"

    Click More info, then Run anyway.

    "Smart App Control blocked an app"

    Windows has no per-app exception for this. Install by hand instead: it takes a minute and gives the same result.

    "Access denied" in the log

    Close the Updater, right-click it and choose Run as administrator.

    Questions

    Good to know.

    Which versions of the game does it support?

    World of Warcraft Retail 12.x and WoW Forever. The same install works on both; modules a client can't support switch themselves off there.

    Will updating reset my settings?

    No. Your settings live in the WTF folder, and both the Updater and a manual install only replace folders in Interface\AddOns.

    How do I turn a module off?

    Every module has a power button next to its name in the settings sidebar. Some take effect at once, others after a /reload.

    How do I move things around?

    Type /unlock or pick Unlock Mode at the top of the sidebar. Drag elements, snap them to each other or to a screen edge, and use an element's cog menu to type exact offsets.

    Can I share my setup with a friend?

    Yes. Open Profiles & Presets, export your profile as a string and send it. They paste it into Import. Full Export covers the whole suite at once.

    Does it work next to my other addons?

    Yes. Turn off any MidnightEssentials module you'd rather use another addon for. Bags switches itself off if you already use another bag addon, such as Baganator or Bagnon, until you choose which one to keep. Nameplate Auras is built to sit on top of whichever nameplate addon you use, or Blizzard's own.

    Where do I report a bug?

    In the #bug-reports channel on the Discord. Include what you were doing, and the error text if one appeared.

    Is it free?

    Yes, completely. If you'd like to support development, there's a Patreon, but nothing is locked behind it.
