# midnightessentials.me

Static site for MidnightEssentials, served by GitHub Pages.

- `index.html` home page, `patch-notes.html` patch notes
- `assets/` styles, script, screenshots, Inter font, Lenis (smooth scrolling)

## What updates by itself

The version number, the Download buttons and the patch notes are read from the
GitHub releases of NotOpti/MidnightEssentials every time someone opens the site.
Publish a new release there (tag = version, notes in the description,
`MidnightEssentials.zip` attached) and the site shows it. Nothing here needs editing.

The Updater download works the same way: the button points at the newest release of
NotOpti/MidnightEssentials-Updater. Keep the attached file named
`MidnightEssentialsUpdater.exe` and every new release is picked up by itself.

## What you update by hand

- New screenshots: replace the file in `assets/img/` with the same name.
